03 / HOW TO READ THESE RESULTS

What the evaluation tells us

Performance is uneven. These limitations matter more than a single headline accuracy score.

A

Binary task is more reliable

Both models separate Normal from Attack reasonably well, but Attack recall remains around 0.64–0.67. Some malicious records are still classified as Normal.

B

R2L distribution shift

The official test set contains 2,885 R2L records, compared with only 995 in training. The model sees a very different class balance at evaluation time.

C

U2R has low support

Only 67 U2R records occur in the official test split. Its per-class scores are therefore statistically unstable.

Evaluation integrity: hyperparameters were selected using training-only cross-validation. The official KDDTest+ split was held back for final evaluation and must not be used to tune the models. The confusion-matrix images and full JSON reports are generated locally under reports/official_evaluation/ and are excluded from Git, so this page does not invent or display matrix counts that are not stored in the repository.

TRAINING DATA

NSL-KDD benchmark

Models were trained on the official KDDTrain+ split containing 125,973 records and evaluated separately on KDDTest+ containing 22,544 records.

40model input features
2independent Random Forest pipelines
5attack/normal output classes in multiclass mode
PREPROCESSING

Consistent feature transformation

Numerical features are standardized with StandardScaler. The protocol, service and flag categorical features are one-hot encoded. The fitted preprocessing steps are stored together with each classifier in the Joblib pipeline.
